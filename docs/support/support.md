# Feedback & Support

- **Bugs and ideas:** use the bug icon in the top bar, or [open a GitHub issue](https://github.com/physiomelinks/phlynx/issues/new). Check the [FAQs](./faq-and-troubleshooting.md) first.
- **Include:** steps to reproduce, a screenshot, and your saved workspace file if possible.
- **Contributing code:** see the [Developer Guide](../guides/develop-phlynx.md).
